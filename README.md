# 个人账单分析工具

本地运行的 Windows 账单分析工具。导入微信、支付宝、银行及其他 CSV/Excel 账单后，自动跳过重复记录、自动分类，并给出本月花了多少、花在哪。

## 直接运行（开发/未打包时）

环境要求：Python 3.10+。

```powershell
cd 当前目录
py -m pip install -r requirements.txt
py run.py
```

启动后会自动弹出本地窗口；如果本机没有安装 `pywebview`，会改用系统默认浏览器打开。

## 打包成单个 exe

```powershell
cd 当前目录
.\build_exe.bat
```

完成后，单文件程序在：

```text
output\dist\个人账单分析工具.exe
```

## 数据位置

数据库只保存在本机：

```text
%LOCALAPPDATA%\BillAnalyzer\bill_data.db
```

默认仅在本机处理账单，前端没有 CDN 引用。只有用户在「待确认」页主动请求 AI 分类建议时，才向所选服务商发送分类所需字段；整份账单文件和数据库不会上传。

## 账单格式

- 支持 `.csv`、`.xlsx`、`.xls`；CSV 可使用逗号、分号、制表符或竖线分隔，常见 UTF-8、GB18030 编码会自动识别。
- 微信、支付宝、中国银行原有格式继续支持；其他平台或银行的表格会根据日期、金额、收支、对方和摘要等列识别，并标记为「其他账单」。Excel 会查找包含账单的工作表。
- 遇到不认识的表头，可在导入结果中选择工作表、表头行和对应列，再用同一文件导入。
- 只有一个正数金额列且没有收支方向时，导入前会要求选择默认方向，避免把收入误算为支出。带正负号的金额列按正数收入、负数支出处理。

导入同一份文件重复时，已存在记录会自动跳过，并在结果中显示跳过条数。

## 不记录

账单明细中的“移至不记录”会将交易移到侧栏的独立页面；导入时自动排除的条目也在这里。它们保留原账本和排除原因，不参与总账单明细、月度汇总、独立账本统计、AI 分类或默认 Excel 导出。点“恢复到账单”即可重新计入；已删除的记录仍按原有删除逻辑处理。

页面交互参考了 [Actual Budget 对预算内外交易的区分](https://github.com/actualbudget/actual/blob/master/packages/docs/docs/api/reference.md)；实现沿用本软件已有的“不计入”标记，以便原有数据直接显示。

## 明细中的标签与账本

明细表直接显示每笔交易的标签和所属账本。点击“+ 标签”或“编辑”可多选已有标签、新建标签，并按标签筛选明细。账本列可直接切换账本，或选择“新建账本”并把当前交易移进去；上方也有独立的新建账本按钮。新账本默认不纳入总汇总，创建时可勾选纳入。参考 [Actual Budget 的交易标签](https://actualbudget.org/docs/transactions/tags/) 和 [账本编辑操作](https://actualbudget.org/docs/transactions/bulk-editing/)。

## 个性化分类与 AI 建议

手动确认一笔普通商户的分类后，软件会记住该商户，并把已有的同方向、仍为「其他」的交易一起归类。淘宝、支付宝等用途混杂的平台只记具体交易说明；如果同一商户出现不同的人工分类，也不会继续套用宽泛规则。「自动分类」按钮还会复用本机已确认的相同商户和商品说明。

侧栏或「待确认」页的「API 管理」会打开独立设置窗口。可分别配置 OpenAI 和 DeepSeek 的模型及密钥，切换当前服务、测试连接或删除本机保存的密钥。窗口显示已保存密钥的尾号和最近一次测试成功或失败的时间；密钥保存后即可主动查看全文，30 秒后自动收起；测试成功时也会短暂显示本次使用的密钥。更换密钥或模型会清除旧测试状态。删除只清除本机配置；如需让密钥在服务商端失效，还要到其控制台撤销。

测试连接只发送一句测试文字；按批次生成建议时才发送账单分类所需字段。API 密钥使用 Windows DPAPI 按当前 Windows 用户加密保存；普通设置接口只返回尾号和测试状态，完整密钥仅在主动查看时返回。软件只发送商户、说明、备注、金额、收支方向和少量人工确认示例；长数字、链接和邮箱会先遮盖。AI 建议不会自动改动账本，需逐笔采用，或在看过建议后采用 AI 自评较高的一批。连接测试和分类请求都可能产生服务商费用。

API 管理交互参考了 [Open WebUI 的连接管理与密钥显隐](https://github.com/open-webui/open-webui/blob/main/src/lib/components/AddConnectionModal.svelte) 和 [Chatbox 的连接测试结果展示](https://github.com/chatboxai/chatbox/blob/main/src/renderer/routes/settings/provider/%24providerId.tsx)。

## 月度预算

在「汇总」页选择月份并填写支出预算，保存后会显示已支出、剩余额度和超支状态。预算按纳入汇总且标记为「计入」的支出计算；收入、重复记录和已排除记录不会占用预算。预算保存在同一个本地数据库中，可随时修改或清除。

汇总页还会列出该月金额最高的 5 笔有效支出，方便核对大额消费。
